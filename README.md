# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/your-username/Python-Mini-Projects.git
```

## Navigate to Project

```bash
cd Python-Mini-Projects
```

## Run Any Project

Example:

```bash
python qrcodegen.py
```

or

```bash
python tic_tac_toe.py
```

---

# 📦 Required Libraries

Install required packages before running the projects.

```bash
pip install qrcode
pip install pillow
pip install pywhatkit
```
